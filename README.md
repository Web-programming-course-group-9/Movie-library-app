# Movie-library-app

Elokuvasovellus — Web-ohjelmoinnin sovellusprojekti (OAMK, Informaatioteknologia, syksy 2026).

Web-sivusto leffaharrastajille. Data haetaan The Movie Database (TMDB) -rajapinnasta.
Katso [CLAUDE.md](./CLAUDE.md) tekniikoiden, kansiorakenteen ja ominaisuuksien osalta.

## Kehitys

```bash
# Frontend
npm install
npm run dev

# Backend
cd server
npm install
npm run dev
```
